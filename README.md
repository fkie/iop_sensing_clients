This repository is part of [ROS/IOP Bridge](https://github.com/fkie/iop_core/blob/noetic/README.md).

[![noetic](https://github.com/fkie/iop_sensing_clients/actions/workflows/main.yaml/badge.svg)](https://github.com/fkie/iop_sensing_clients/actions/workflows/main.yaml)

The repository contains clients designed to control services on IOP complient robot. All client services are based on ```SlaveHandlerInterface``` and use funtionality of [Slave](https://github.com/fkie/iop_core/blob/noetic/fkie_iop_ocu_slavelib/README.md).  

### List of service plugins in this repository:

[fkie_iop_client_costmap2d: CostMap2DClient](fkie_iop_client_costmap2d/README.md)  
[fkie_iop_client_measurement_sensor: MeasurementSensor](fkie_iop_client_measurement_sensor/README.md)  
[fkie_iop_client_path_reporter: PathReporter](fkie_iop_client_path_reporter/README.md)
